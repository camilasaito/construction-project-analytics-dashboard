# Validation Process

The dashboard was validated throughout the development process to make sure the Tableau results matched the expected KPI logic.

The main validation steps included:

- Reviewing the existing report and business rules
- Using SQL queries to check totals and KPI calculations
- Comparing SQL results with Tableau outputs
- Testing project filters and dashboard interactions
- Reviewing unexpected differences and adjusting calculations when needed

For this portfolio version, all examples use synthetic data and do not include client-specific information.
