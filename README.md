# Construction Project Analytics Dashboard

This capstone project focused on developing a Tableau dashboard for construction project reporting. The dashboard brings operational and safety information into one project-level view and recreates existing KPI logic in Tableau.

## My Role

My main contributions included:

- Exploring the reporting database to identify relevant tables and fields
- Using SQL to validate KPI logic and dashboard results
- Developing the final dashboard in Tableau
- Creating Tableau calculated fields for operational and safety KPIs
- Testing filters, calculations, and dashboard behaviour
- Documenting KPI definitions and validation steps
