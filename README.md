# Construction Project Analytics Dashboard

## About the Project

This capstone project focused on building a Tableau dashboard for construction project reporting. The dashboard brings operational and safety information into one project-level view.

The project involved exploring read-only reporting databases, validating KPI logic with SQL, and recreating the required calculations in Tableau.

## My Role

My main contributions were:

* Exploring the databases to identify the right tables and fields
* Using SQL to validate KPI results
* Building the dashboard in Tableau
* Creating and testing Tableau calculated fields
* Testing filters and dashboard results
* Participating in meetings and applying stakeholder feedback
