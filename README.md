# Construction Project Analytics Dashboard

## About the Project

This capstone project focused on developing a Tableau dashboard for construction project reporting. The goal was to bring operational and safety information into one project-level view and recreate existing KPI logic in Tableau.

## My Role

My main contributions included:

- Exploring the reporting database to identify relevant tables and fields
- Using SQL to validate KPI logic and dashboard results
- Developing the final dashboard in Tableau
- Creating Tableau calculated fields
- Testing filters and calculations
- Documenting the validation process
